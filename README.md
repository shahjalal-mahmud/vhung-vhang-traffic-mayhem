## 🎮 About the Game

**VhungVhang: Traffic Mayhem** is a 2D traffic management arcade game inspired by the chaotic roads of Bangladesh.

Take control of a busy city intersection and manage the traffic flow to prevent accidents. Control traffic signals, allow vehicles to pass safely, and keep the intersection running smoothly for as long as possible.

As time passes, traffic becomes heavier and faster, making your job increasingly challenging. How long can you maintain order before everything turns into complete *VhungVhang*?

## 🕹️ How to Play

Your objective is to manage traffic at a busy four-way intersection and prevent vehicle collisions.

### Controls

| Key   | Action                      |
| ----- | --------------------------- |
| `1`   | Control North–South traffic |
| `2`   | Control East–West traffic   |
| `P`   | Pause / Resume              |
| `R`   | Restart the game            |
| `ESC` | Quit the game               |

*Note: Controls may be updated during development.*

### Gameplay Rules

1. Manage traffic signals to control vehicles approaching the intersection.
2. Allow vehicles to cross the intersection safely.
3. Prevent vehicles from colliding with each other.
4. Earn points for successfully passing vehicles.
5. Avoid accidents and survive as long as possible.
6. Traffic speed and density increase as your score grows.

## ✨ Features

- **Traffic Management:** Control traffic flow at a four-way intersection.
- **Bangladeshi Vehicles:** A variety of vehicles inspired by local roads, including rickshaws, CNGs, motorcycles, cars, buses, and trucks.
- **Traffic Signal System:** Manage traffic signals to prevent conflicting traffic movements.
- **Collision Detection:** Detect vehicle collisions and handle accidents.
- **Dynamic Traffic:** Vehicles continuously enter the intersection with varying speeds.
- **Progressive Difficulty:** Traffic density and speed increase over time.
- **Scoring System:** Earn points for safely passing vehicles.
- **Life System:** Get multiple chances before the game ends.
- **High Score:** Save and track your best score.
- **Pause & Resume:** Take a break during gameplay.
- **Game Over Screen:** View your final score and highest score.
- **Restart Option:** Start a new game whenever you want.
- **Cartoon-Style Graphics:** Colorful 2D visuals and animated vehicles.
- **Sound Effects:** Audio feedback for gameplay events.

## ⚙️ Installation & Setup

### Requirements

- Python 3.10 or later
- Pygame

### 1. Clone the Repository

```bash
git clone https://github.com/shahjalal-mahmud/vhung-vhang-traffic-mayhem.git
```

### 2. Navigate to the Project Directory

```bash
cd vhung-vhang-traffic-mayhem
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

Alternatively:

```bash
pip install pygame
```

### 4. Run the Game

```bash
python main.py
```
